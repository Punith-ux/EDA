# Exploratory Data Analysis Project

## Overview
This project performs Exploratory Data Analysis on the Titanic dataset using Python and ydata-profiling.

## Technologies Used
- Python
- Pandas
- NumPy
- ydata-profiling
- Jupyter Notebook

## How to Run

Install dependencies:

pip install pandas numpy ydata-profiling notebook

Run Jupyter Notebook:

jupyter notebook

## Output
- HTML profiling report
- Dataset analysis
- Statistical insights
